# nuget-dep-graph

Инструмент для визуализации графа зависимостей пакетов NuGet (.NET).

## Общее описание

Программа по имени пакета и его версии строит граф зависимостей
из метаданных `.nuspec` и сохраняет его в PNG и PlantUML.

Готовые менеджеры пакетов (`nuget`, `dotnet`, `NuGet.Client`)
не используются — только стандартная библиотека Python и Pillow
для рисования PNG.

Есть два режима:
- `online` — пакеты скачиваются с NuGet v3 API;
- `offline` — берётся JSON-файл с описанием тестового графа.

## Описание функций и настроек

### Параметры командной строки

- `--package` — имя пакета (обязательный);
- `--source` — URL NuGet или путь к JSON-файлу (обязательный);
- `--mode` — `online` или `offline` (по умолчанию `online`);
- `--version` — версия пакета (в `online` обязательна, `latest`
  не принимается);
- `--output` — имя PNG-файла (по умолчанию `graph.png`);
  рядом сохраняется `.puml` с тем же именем;
- `--filter` — подстрока; пакеты с ней и их поддеревья исключаются;
- `--reverse` — показать, кто зависит от пакета (только `offline`).

### Формат тестового репозитория (offline)

JSON, где ключ — пакет, значение — список его зависимостей:

```json
{
  "A": ["B", "C"],
  "B": ["D"],
  "C": ["D"],
  "D": []
}
