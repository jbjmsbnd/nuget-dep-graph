# nuget-dep-graph

Инструмент визуализации графа зависимостей для менеджера пакетов NuGet (.NET).

## Общее описание

Утилита командной строки, которая по имени пакета и его версии строит
транзитивный граф зависимостей на основе метаданных `.nuspec` из
репозитория NuGet, поддерживает фильтрацию пакетов, поиск обратных
зависимостей и визуализацию графа (PlantUML / PNG).

Готовые менеджеры пакетов и библиотеки получения зависимостей
(`nuget`, `dotnet`, `NuGet.Client` и т.п.) не используются —
только стандартная библиотека Python (`argparse`, `urllib.request`,
`xml.etree.ElementTree`, `json`, `zipfile`).

Поддерживаются два режима работы:

- `online` — запросы к NuGet v3 API по HTTP, обход транзитивных
  зависимостей через `.nuspec` реальных пакетов;
- `offline` — вместо URL передаётся путь к JSON-файлу описания
  тестового графа (используется для демонстрации обхода, фильтрации,
  обработки циклов и поиска обратных зависимостей без сети).

## Описание всех функций и настроек

### CLI-параметры

- `--package` — имя анализируемого пакета (обязательный);
- `--source` — URL репозитория NuGet (service index) для онлайн-режима
  или путь к JSON-файлу тестового репозитория для оффлайн-режима
  (обязательный);
- `--mode` — режим работы: `online` (по умолчанию) или `offline`;
- `--version` — версия пакета. Для онлайн-режима обязательна явная
  версия (значение `latest` отклоняется). Для оффлайн-режима
  игнорируется;
- `--output` — имя файла с изображением графа (`graph.png`);
- `--filter` — подстрока для фильтрации пакетов: узлы, чьё имя
  содержит подстроку, и их поддеревья исключаются из графа;
- `--reverse` — поиск транзитивных обратных зависимостей (кто зависит
  от `--package`). Поддерживается только в оффлайн-режиме.

### Формат тестового репозитория (offline)

JSON-объект, где ключ — имя пакета, значение — список его прямых
зависимостей:

```json
{
  "A": ["B", "C"],
  "B": ["D"],
  "C": ["D"],
  "D": []
}
